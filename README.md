File guide

1. Aldabra data:

Raw ITS2 sequencing data is accessible under NCBI's BioProject ID PRJNA1465797

20260116T164045_hoongbe1.zip: raw SymPortal output for Aldabra samples

bleaching_data.csv: bleaching data for Aldabra samples during the fourth global mass bleaching event

seq_absolute_abundance.csv: absolute abundance of ITS2 sequence variants

seq_relative_abundance.csv: relative abundance of ITS2 sequence variants

its2_type_profiles_absolute.csv: absolute abundance of ITS2 type profiles

its2_type_profiles_relative.csv: relative abundance of ITS2 type profiles




2. Indo-Pacific data:

r_processed_profile_matrix.xlsx: matrix of individual samples and their ITS2 type profiles

sample_metadata_aldabra.xlsx: metadata of all samples across the Indo-Pacific

sample_profile_list.xlsx: list of ITS2 type profiles associated with each individual sample

c15_profile_metadata.xlsx: Cladocopium C15 profiles and their distribution across the Indo-Pacific

manual_unifrac_profile_distances_C15_no_sqrt.dist: UniFrac distances among C15 profiles

manual_unifrac_profile_distances_C15_sqrt.dist: UniFrac distances among C15 profiles (square-root transformed)

manual_unifrac_profiles_PCoA_coords_C15_no_sqrt.csv: PCoA coordinates among C15 profiles

manual_unifrac_profiles_PCoA_coords_C15_sqrt.csv: PCoA coordinates among C15 profiles (square-root transformed)




3. Analyses files:

map.qmd: map of sampling locations at Aldabra

symportal_output.qmd: visualisation of SymPortal output data for Aldabra samples

lagoon_vs_sea.qmd: comparison of symbiont communities between the lagoon and seaward reef

meta_analysis.qmd: all analyses involving the cross-study Indo-Pacific dataset
